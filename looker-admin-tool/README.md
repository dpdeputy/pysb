# Looker Admin Tool

A tool to administer multiple Looker instances and projects.

[![CI/CD Pipeline](https://gitlab.com/example/looker-admin-tool/badges/main/pipeline.svg)](https://gitlab.com/example/looker-admin-tool/-/pipelines)
[![codecov](https://codecov.io/gl/example/looker-admin-tool/branch/main/graph/badge.svg)](https://codecov.io/gl/example/looker-admin-tool)

This repository serves as a quick-start template for new Python projects, incorporating modern development practices and tooling.

## Features

-   **Modern Packaging:** Uses `pyproject.toml` with the `hatchling` build backend.
-   **Dependency Management:** Managed with `uv` for fast, reliable dependency resolution.
-   **Code Quality:** Enforced with `ruff` for linting/formatting and `mypy` for type checking.
-   **Automated Testing:** `pytest` for running unit and integration tests.
-   **Pre-commit Hooks:** Automates code quality checks before every commit.
-   **CI/CD:** A complete GitLab CI pipeline for automated testing and releases.
-   **Documentation:** A full documentation site built with `MkDocs` and the Material theme.
