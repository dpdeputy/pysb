### Added
- Initial project structure with `src` layout.
- `pyproject.toml` with `hatchling` build system.
- `ruff`, `mypy`, and `pytest` for code quality and testing.
- `.pre-commit-config.yaml` for automated code quality checks.
- `uv` for dependency management.
- Core package modules including exceptions, configuration, and interfaces.
- Example `User` domain model and in-memory `UserRepository`.
- GitLab CI pipeline for automated testing and releases.
- MkDocs documentation system with Material theme.
- Comprehensive `README.md` and initial user/developer guides.
