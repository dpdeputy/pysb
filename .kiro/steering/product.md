# Product Overview

## Purpose
pysb (Python Sandbox) is a comprehensive quick-start repository template that demonstrates modern Python development practices. It serves as a foundation for new Python projects, providing industry best practices, proper project structure, and pre-configured tooling.

## Key Features
- Modern Python packaging with src-layout structure
- Pre-configured development tools (testing, linting, formatting, type checking)
- Example domain models using Pydantic for data validation
- Automated CI/CD with GitLab
- Comprehensive documentation system with MkDocs
- Semantic versioning and automated releases
- Repository pattern examples and clean architecture demonstrations

## Target Users
Python developers who want to bootstrap new projects with established best practices and avoid manual setup of development tooling and project structure.

## Architecture Philosophy
- Emphasizes simplicity, maintainability, and adherence to current Python ecosystem standards
- Demonstrates clean architecture with proper separation of concerns
- Uses Pydantic for domain models and data validation
- Follows modern Python packaging standards (PEP 518/621)
